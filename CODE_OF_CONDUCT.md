# Code of Conduct

Project spaces require respectful, evidence-oriented collaboration. Harassment,
threats, discriminatory conduct, doxxing, credential exposure, and knowingly
misleading security claims are not acceptable.

Technical disagreement is expected. Challenge claims with reproducible evidence
and address the work rather than the person. Until a public moderation roster
exists, the repository owner handles reports through a private channel already
known to the reporter. This bootstrap policy must be replaced before a broader
community is formally onboarded.
